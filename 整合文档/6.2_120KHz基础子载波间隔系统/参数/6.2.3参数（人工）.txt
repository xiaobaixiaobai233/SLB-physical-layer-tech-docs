# 6.2.3 物理层信号 — 模块实现参数清单（补全）
# airMode=slb；命名遵循 nearlink-naming
# 规则：实现本模块所需参数全部列出；若依赖他模块算出的量，只写「他模块输出」，不展开他模块入参。
# 共性：多数 RS 写 a_{k,l}=r_{n,l}(k)（k≠80）；r_{n,l}(k) 统一引用 6.5.3 输出，不在本册展开 Gold/c_init。

────────────────────────────────────────
6.2.3.1 同步信号 FTS / STS
建议 API: slbGenerateFtsSequence / slbMapFts / slbGenerateStsSequence / slbMapSts
────────────────────────────────────────
【本模块输出】
  ftsSequence[]              d_FTS(k)，ZC 型；k=0..160，k=80→0
  stsSequence[]              2√2 · d_STS(k)，梳状；仅 n≡0(mod 8) 且 n≠80
  ftsRootIndexU              FTS 根标识 u ∈ {1,160,2,159}
  stsRootIndexU              STS 根标识 u = 1..16（G-ID/先发节点 ID 低4位+1）
  ftsMappedRe                FTS 映射：SAB/RAB #1,#2；首符号 CP 加倍、次符号无 CP
  stsMappedRe                STS 映射：SAB/RAB #0（或无 SAB 时该帧 #0）

【本模块直接入参】
  L0: subcarrierCount(=161), dcSubcarrierIndex(=80)
  L1/场景: domainType（通信域/直通/RAB）, symbolType（决定 FTS u=1 或 160）
  L1: gNodeIdLow4 或 passthroughFirstNodeIdLow4（供 STS u）
  引用 → 6.2.2.1 输出: symbolType, generalCpLenTs（FTS 首符号 2×CP）
  引用 → 6.2.2.7 输出: reIndexKl / resourceGrid 写入接口（aKlComplex）
  引用 → 6.2.2.2 输出: nSymFrame（符号号合法范围）
  引用 → 6.2.4 输出: sabRabSymbolLayout（#0/#1/#2 布局，仅引用控制块输出）

【不展开】
  6.5.9 通用 ZC 框架参数（本节用闭式公式，不走 6.5.9）
  6.2.4 字段比特语义

────────────────────────────────────────
6.2.3.2 信道探测信号 SRS
建议 API: slbGenerateSrsSequence / slbMapSrs
────────────────────────────────────────
【本模块输出】
  srsMappedRe                T 链路符号上 a_{k,l}=r_{n,l}(k)（梳齿映射后）
  srsCombSubcarriers[]       梳齿子载波集合（来自 srs-Set-Conf）
  srsAntennaPortP0           单/多端口时仅 p0 映射，其余端口 0

【本模块直接入参】
  L1: srsSetConf（高层 srs-Set-Conf：梳齿/资源/预配置激活）
  运行时: radioFrameIndex n, symbolIndex l, antennaPortIndex p / p0
  引用 → 6.5.3 输出: rsQpskSequence r_{n,l}(k)   ★不展开 c_init/N_ID/N_CP
  引用 → 6.2.2.7 输出: reIndexKl / aKlComplex 写入
  引用 → 6.2.2.9 输出: gtaLinkSymbolType（须为 T 符号）
  引用 → 6.2.4 输出: srsPreconfigActivate（预配置激活指示，仅引用）

6.2.3.6 数据信息解调参考信号 DMRS-D
建议 API: slbGenerateDmrsSequence(kind=dmrsD) / slbMapDmrs
────────────────────────────────────────
【本模块输出】
  dmrsDMappedRe              调度数据符号内连续 N 个符号上的 RE 映射
  dmrsDSymbolCountN          N = N_port / N_comb
  dmrsDCombCount             N_comb ∈ {1,2}
  dmrsDPortCount             N_port（端口总数量）
  dmrsDPortRangePerSymbol    第 M 符号端口区间 [M·N_comb, M·N_comb+N_comb)
  dmrsDTimeGranularity       时域周期（默认 1 无线帧；跨 SAB 以含 SAB 载波为准）

【本模块直接入参】

  引用 → 6.5.3 输出: rsQpskSequence r_{n,l}(k)
  引用 → 6.2.2.7 输出: reIndexKl / aKlComplex
  引用 → 6.2.2.9 输出: gtaLinkSymbolType（G/T/A）
  引用 → 6.2.2.10 输出: dSymbolContext（直通数据）
  引用 → 6.2.4 输出: hasSabInCarrier（跨载波时域起点）

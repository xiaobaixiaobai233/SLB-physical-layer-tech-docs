# SLB 物理层参数登记册（Param Registry）

> 面向 AI 分模块实现物理层协议时的**跨模块参数真源（SSOT）**。  
> 协作：Skill `slb-param-registry` + `nearlink-naming`（**强制 `airMode=slb`**）。  
> 当前覆盖：L0+L1、SessionConfig、L2 函数级 Phase A、**L3 跨模块交换**；并与 6.2 / 6.5 / 6.6 分册模块 I/O 汇总对齐。

---

## 1. 背景

工作链路：

1. 按协议节号整理**技术文档**（边界、参数、步骤、约束）；
2. 按模块做**实现参数清单**（本模块输出 / 直接入参 / 他模块输出）；
3. 汇总进本目录登记册 + 分册 L0–L3 PDF，再 vibecode。

缺口若无登记册，则容易：同名异义、私建 magic number、不清楚读写所有权、把上游入参重复抄进下游。

---

## 2. 四层模型

| 层 | 含义 | 写 | 读 | 本目录产物 |
|----|------|----|----|------------|
| **L0** | 系统常量 | 无（只读表） | 全 PHY | `SLB物理层L0-L1参数登记册初稿` |
| **L1** | 会话/上层下发 → `SlbPhySessionConfig` | MAC/第7章/调度 | PHY 只读 | 同上 + SessionConfig 字段表 |
| **L2** | 模块/函数专有可调 | 本模块 owner | 本模块+边界 | `SLB物理层L2按模块参数登记册PhaseA粗提` |
| **L3** | 运行时交换（测量/命令/IE） | 生产者 | 消费者 | `SLB物理层L3跨模块交换登记册` |

状态：`frozen` | `draft` | `tbd`。

## 3. 硬约束（与 Skill 一致）

### 3.1 命名

- 仅 `airMode=slb`；类型 `Slb*`，函数 `slb`+动词，字段 lowerCamelCase。
- 有量纲必须带单位后缀（`Hz`/`Us`/`Dbm`/`M`/`Ts`…）。
- 协议词用 SLB 术语（`gNode`/`tLink`/`pms`/`sab`…），禁止泛无线同义替换。

### 3.2 嵌套引用（他模块）

依赖他模块时：**只引用该模块的输出工程名**，禁止把上游内部入参再抄一遍。

例：6.2.3 映射 RS → 只写 `6.5.3 伪随机QPSK` 的 `rsQpskSequence`，不展开 Gold/`c_init` 入参。

### 3.3 节号可读性

凡出现协议节号，必须带中文名：

| 错误 | 正确 |
|------|------|
| `6.6.1` | `6.6.1 角色与汇聚` |
| `6.2.3.9；6.5.5.8` | `6.2.3.9 PMS波形；6.5.5.8 AoA角度` |

LaTeX 约定：`\modref{节号}{中文短名}` → 排版为斜体「节号~中文短名」。

### 3.4 排版防叠字

长 `id` / 工程名用 `\ideng{id}{eng}` **上下叠排** + `xurl` `\path`，禁止单列挤爆导致叠字。

## 4. 推荐工作流（分册 → 登记册）

对每个协议分册（如 6.2 / 6.5 / 6.6）：

1. **模块参数 txt**：按子节列「输出 / 直接入参 / 他模块（节号+中文名+输出名）」。
2. **模块实现参数汇总.pdf**：嵌套 I/O 表；他模块列用 `\modref`。
3. **参数 L0–L3 四层整合.pdf**：本分册去重；生产者/消费者/边界表带中文名。
4. **回写本目录**：L0/L1 冲突合并进 L0–L1 册；L3 交换合并进 L3 册；Session 字段同步字段表。

```
分册技术文档
  → 模块参数.txt（详尽 I/O，嵌套只引输出）
  → *模块实现参数汇总.tex/.pdf
  → *参数L0-L3四层整合.tex/.pdf
  → 参数登记册/（L0–L1 / L2 / L3 / SessionConfig）
```

## 6. 合作者该做 / 不该做

| 该做 | 不该做 |
|------|--------|
| 用 Skill 只提**自己分册**相关参数，合并进本目录 | 另写一份互不相干的「全局参数表」 |
| 他模块只写「节号+中文名 + 输出工程名」 | 把上游入参整表复制进下游 |
| 工程名过 `nearlink-naming` 自检 | 私建 `120000`、`161` 等 magic number |
| 冲突先改登记册再改代码 | 静默覆盖他人 `id` |

1. 汇总本组相关文档的 L0/L1，组内评审对齐。  
2. L1 与上层仿真平台 SessionConfig 对齐（只读消费）。  
3. 实现优先库：L2 Phase B（范围/默认/拒配 → `frozen`）+ 接口暴露补 L3。

## 7. 给 AI / 实现者的提示

```
Use slb-param-registry skill together with nearlink-naming. airMode=slb.
Nested rule: cite other-module OUTPUTS only (section + Chinese title).
Update: 参数登记册/ and chapter *模块实现参数汇总 / *L0-L3.
```

1. L0/L1 **只引用、不改写**（升 frozen 须经评审）；  
2. 新跨模块量：先登记 `draft`，再改文档/代码；  
3. 模块表与登记册冲突：**先改分册再回写登记册**。
